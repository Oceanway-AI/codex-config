# Oceanway Config 使用说明

Oceanway Config 基于 CC Switch，帮助你把 Oceanway API 配到本机的 Codex、Claude Code 等应用。首次使用按首页三个步骤操作即可。

本版提供 Codex、Claude Code、Gemini CLI、OpenCode、OpenClaw 的 Oceanway 接入。其他应用的安装与历史管理入口保留，接入状态以页面显示为准。

## 1. 连接 Oceanway

打开应用，在“连接 Oceanway”中粘贴 API Key，点击“连接并继续”。服务地址已配好，无需填写。

连接成功后，应用会读取这个 Key 可用的模型，并收起 Key 输入框。需要换 Key 时点击“更换 Key”，重新连接。

## 2. 选择应用

首页直接显示 Codex 和 Claude Code，已安装的常用应用默认勾选。还没安装时，点击卡片上的“安装”进入官方安装页面；安装完成后回到这里点“重新检测”。左下角“应用”保留完整的安装、升级、卸载和检测入口，其他 Agent 可从“其他应用”展开。

模型会自动选好：Codex 默认 GPT，Claude Code 默认 Claude，Gemini CLI 默认 Gemini。点击模型旁的“更换”，可以查看完整可用清单，选择其他模型。生图使用单独的图片模型，点击“生图设置”可以调整。

选好应用后点击“一键配置”。如果 Key 没有图片模型权限，页面会提示，你仍可先完成对话配置。

## 3. 开始使用

配置结果会逐个显示应用状态。成功后点击“打开”进入对应 Agent；CLI 会打开新终端，Codex 桌面版需要重新加载时会先让你确认已保存工作，再关闭并重新打开。保存配置本身不会自动关闭应用。

如果某项失败，结果会显示原因；已经成功的项目会保留。点击“返回调整”可重新配置。

## 在对话中生图

一键配置会给 Codex、Claude Code、Gemini CLI、OpenCode 注册 Oceanway 图片 MCP，并写入默认生图规则。OpenClaw 当前仅支持对话接入，图片功能尚未适配。打开新会话后，直接用自然语言描述图片，例如：

> 帮我生成两张不同构图的海边咖啡馆宣传图。

Agent 会通过 Oceanway 图片工具提交任务，多张图片可以并行生成，再把结果返回当前会话。生图使用 Key 有权限的图片模型。若提示没有图片模型，先确认该 Key 已开通图片能力，再重新连接配置。

## 查找以前的会话

点击侧栏“会话”，可以集中查看各 Agent 保存在本机的记录。选择应用，按项目或时间分组，搜索标题、摘要、会话 ID 或目录；打开某条记录后可阅读消息、图片和工具调用，在正文里查找，复制单轮或整段对话，并导出 Markdown。

Codex 的普通与归档会话都会读取。隐藏某个侧栏应用入口后，已有历史仍能在会话页找到。Claude Desktop 入口显示的是本地 Claude Code 记录。

接入 Oceanway 时会自动完成历史可见性兼容：先备份，再处理必要的供应商标记，保留会话 ID、正文和附件；无需单独迁移。需要回到 Agent 继续时，可复制“恢复命令”在原项目目录运行；macOS 还可直接在所选终端恢复。旧会话能否继续由 Agent 与原会话状态决定。

阅读、搜索和复制不会删除记录。会话页的“删除”是永久删除，必须在确认框中确认后才执行。

## 其他入口

| 入口              | 用途                                                       |
| ----------------- | ---------------------------------------------------------- |
| 高级功能 → MCP    | 添加、编辑、导入工具服务，选择同步到哪些应用               |
| 高级功能 → Skills | 查找、安装和管理技能，选择使用技能的应用                   |
| 高级功能 → 提示词 | 编辑、启用、导入和复制提示词                               |
| 用量统计          | 查看本地记录汇总的请求、Token 和费用估算，按应用及日期筛选 |
| 应用              | 管理 Agent 的安装、升级、卸载和显示状态                    |
| 设置              | 调整语言、外观、应用目录、网络、备份、导出及日志等         |

## 遇到问题

- **连接失败**：检查 Key 和网络，按页面提示重新连接。
- **安装后未识别**：点击“重新检测”，或到“应用”查看对应安装状态和错误。
- **配置后仍用旧模型**：保存工作后通过结果页打开应用，CLI 使用新终端。
- **会话列表读取失败**：点击“重试”；读取请求失败会明确显示，已加载的记录会保留。
- **图片配置失败**：查看结果页的图片状态，确认 Key 的图片权限后重试。
