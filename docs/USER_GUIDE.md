# codex-config 使用说明

### 一键自动配置与日志

主界面仅需填写或复用 Key 和 Base URL。点击“一键配置并重启”后，软件自动写入配置、回读检查并请求重启 Codex / ChatGPT，不需要逐步确认。请在点击前保存正在进行的任务。任一步失败会停止后续操作，不自动重试。

执行进度与“查看日志”显示当前结果。日志不落盘，仅保留本次打开的最近 200 条，可随时清空。自动完成只表示配置检查通过、已观察到新桌面窗口，不代表图片生成经过实测。

执行时显示四步进度：写入配置、检查配置、重启 Codex、完成，正常情况下自动流转。阻塞时停在对应步骤，可按提示手动处理后点击“重试…并继续”。检查或重启失败后的重试不会重复写入凭据；若修改 Key 或地址，则会重新写入。不会跳过失败检查或仅凭手动确认标记完成。

修改输入会清除旧的完成状态并标记“修改未保存”；恢复默认后进度重新开始。保存、测试和重试都要求有效的 HTTP(S) 地址，不接受内嵌账号密码、查询参数或片段。损坏的认证 JSON 会停止写入，不会静默覆盖。新建备份采用不重复文件名；macOS/Linux 的密钥备份权限为 `0600`，初始备份目录为 `0700`。

若显示“更新通道不可用”，表示未取得有效更新清单，不代表已经是最新版；需要维护者发布带签名的更新资源，不影响本地配置操作。

开发验收：`npm test` 与 `cargo test --manifest-path src-tauri/Cargo.toml` 执行回归测试；`npm run test:ui` 提供仅监听 `127.0.0.1:4186` 的隔离界面，可模拟保存、检查、重启失败。该界面只使用假数据，不读写真实配置、不发送 Key、不重启应用，也不会打包进正式版。

主界面保留 Base URL、Key、一键配置、迁移历史和恢复原配置。诊断和主动图片测试放在高级工具中，不增加日常配置步骤。

本文档适用于 OceanWay AI 用户，用来完成 Codex 的一键配置。

`codex-config` 是一个小工具。您只需要打开软件，填写 API Key，保存正在进行的任务，然后点击“一键配置并重启”即可。自动完成后，在重新打开的 Codex 中新建任务。

## 一、下载软件

请根据您的电脑系统下载对应版本：

- macOS 用户：下载 `codex-config-macOS.zip`
- Windows 用户：下载 `codex-config-Windows` 里的 `.exe` 文件

下载后，请先解压文件。

## 二、macOS 用户如何打开

### 正常打开方式

1. 双击 `codex-config-macOS.zip` 解压。
2. 得到 `codex-config.app`。
3. 将 `codex-config.app` 拖到“应用程序”文件夹。
4. 双击打开。

### 如果提示“已损坏，无法打开”

如果 macOS 提示：

```text
“codex-config”已损坏，无法打开。你应该将它移到废纸篓。
```

这通常不是软件真的损坏，而是 macOS 对未上架 App Store 的软件做了安全限制。

请按下面步骤处理：

1. 打开“终端”应用。
2. 复制下面这行命令。
3. 粘贴到终端里。
4. 按回车。

```bash
xattr -dr com.apple.quarantine /Applications/codex-config.app
```

然后重新双击 `codex-config.app` 打开。

如果您的软件没有放在“应用程序”文件夹，而是在“下载”文件夹，请使用下面这行命令：

```bash
xattr -dr com.apple.quarantine ~/Downloads/codex-config.app
```

## 三、Windows 用户如何打开

1. 下载 Windows 版本。
2. 双击 `.exe` 文件。
3. 如果 Windows 弹出安全提示，请选择“更多信息”，然后点击“仍要运行”。
4. 软件打开后即可开始配置。

## 四、如何完成配置

打开软件后，您会看到两个输入框：

- `API Key`
- `Base URL`

一般情况下，`Base URL` 已经自动填写好了，不需要修改。

您只需要：

1. 在 `API Key` 输入框中粘贴您的 API Key。
2. 确认 `Base URL` 是：

```text
https://ocean-way.top
```

3. 保存正在进行的任务，点击“一键配置并重启”。
4. 等待右侧配置日志显示结果，软件会自动检查配置并重启 Codex。
5. 在重新打开的 Codex 中新建任务。若日志提示失败，请查看问题诊断。

重新打开 Codex 并新建任务后，即可使用 OceanWay AI provider。

无论当前是否登录 ChatGPT，本工具都会使用当前 Codex Desktop 版本兼容性最好的 API Key provider 模式，把 Key 写入 `auth.json` 的 `OPENAI_API_KEY`，并保留已有的其他登录字段。这样可以确保发往 OceanWay 的请求带上标准 `Authorization: Bearer` 认证头。

切换到 API Key provider 后，部分依赖 ChatGPT 登录态的 Codex Mobile、插件、自动化或额度查询功能可能不可用；这不影响 OceanWay 会话本身。

### 图片 MCP

“一键配置并重启”会部署内置原生图片 MCP，并保存三条简短路由规则。默认图片模型为 `gpt-image-2`，用户明确指定其他模型时按指定调用。

- 普通生图通过当前服务的 `/images/generations`。
- 参考图通过 `/images/edits` 上传原图。参考图直接放在 Codex 对话中，无需再传给配置软件。
- 用户要求几张就安排几张；未指定才默认一张。并发最多两个请求不代表总数限制。

图片请求由自动注册的 `oceanway_images` MCP 调用供应商 API，不依赖 imagegen、专用图片 CLI，也不需要用户安装 Node 或 Python。规则只写入当前生效的全局任务指令文件，不再重复注入 `developer_instructions`，并保留用户已有内容。无需每次指定调用路径。配置完成后请新建任务；任务的更高优先级要求仍然生效。

使用旧版配置过的用户可以保持 Key 输入框为空，重新点击一键配置。写入会更新本工具的规则段，不重复叠加；损坏的 TOML、JSON 或任务规则标记会停止操作。

从 v1.2.0 开始，软件会识别已经保存在 Codex 配置中的 OceanWay API Key。重新打开软件后，输入框不会回显完整 Key；保持输入框为空即可继续测试连接或再次完成配置。只有输入新的 Key 时才会覆盖之前保存的值。

安全提醒：Codex 启动的工具命令可以读取配置的 Key。请只在可信的项目和任务中使用。测试图片会产生服务用量，只在用户主动点击测试时发送；超时不会自动重试收费请求。

图片任务保存进度和输出清单；取消只停止未发送的请求，已发送请求可能完成和计费。重启不自动补发收费请求；超时显示结果不确定，只有明确点击重试或要求重试才再次提交。成功项和原图始终保留。

“恢复原配置”恢复首次快照中的认证和 provider，撤销本工具的图片 MCP 和规则，保留其他 MCP、用户指令、桌面偏好、会话及图片。存在本工具记录的历史迁移时仍按原规则撤销，不新增跨供应商会话兼容保证。

## 五、可选：迁移历史可见性

如果您之前使用 OpenAI 账号登录 Codex，切换到 OceanWay AI 后发现旧历史记录不显示，可以点击“迁移历史”。

这个功能不是自动执行的，并且只在当前 provider 是 OceanWay AI 时可用。点击后，软件会先扫描本机 Codex 历史记录，并显示将要迁移的数量。确认后才会开始处理。

迁移历史只会修改本机历史记录里的 provider 元数据，让旧会话在 OceanWay AI 下显示；不会修改对话正文。

迁移前，软件会自动创建备份：

```text
~/.codex/oceanway-history-migration-backup/
```

需要注意：如果某些历史记录包含加密内容，迁移后可能能在列表里看到，但不一定能继续对话或压缩上下文。软件会在确认前提示这个风险。

如果之后点击“恢复默认”，软件会同时撤销由本工具记录过的历史迁移。使用 OceanWay AI 期间新建的会话不会被强行同步到 OpenAI Official。

## 六、如何测试连接

如果您不确定 API Key 是否可用，可以点击“测试连接”。

如果测试成功，说明当前 API Key 和 Base URL 可以连接。

如果测试失败，请检查：

- API Key 是否复制完整。
- API Key 前后是否多了空格。
- 网络是否正常。
- Base URL 是否为 `https://ocean-way.top`。

## 七、问题诊断与运维工具

v1.3.0 增加了右侧工作区：

- `问题诊断`：检查 Provider、API 凭据、图片工具兼容、Codex 版本、服务连接、Codex 运行状态和备份状态。
- `复制脱敏报告`：把检查结果复制给客服，不包含完整 API Key 或访问令牌。
- `重启 Codex`：确认后退出并重新打开 Codex。
- `修复配置`：使用已经保存的 Key 和 Base URL 补全缺失字段。
- `配置与备份目录`：打开本机 Codex 配置目录。

如果诊断显示“Codex 正在运行”，这通常只是提醒您配置后需要重启，并不代表 Codex 本身出现故障。

`额度与权限`页面已预留账户余额、套餐和模型权限结构。在 OceanWay 账户接口接入之前，页面会明确显示“待接入”，不会展示模拟额度。

## 八、软件更新

点击窗口右下角“检查更新”可以检查新版本。发现更新后，按钮会变为“安装 v版本号”；安装完成后软件会自动重启。

为确保安装包没有被替换，软件只接受 OceanWay 发布密钥签名的更新。如果更新通道尚未发布，界面会显示“更新通道尚未发布”，不会影响配置、诊断和运维功能。

## 九、如何恢复默认设置

如果您不想继续使用 OceanWay AI 配置，可以点击“恢复默认”。

恢复后，软件会尽量把 Codex 配置恢复到您第一次使用本工具之前的状态。

如果您之前使用过“迁移历史”，恢复默认也会撤销由本工具记录过的历史迁移。

适用情况：

- 您之前已经配置过其他 Codex provider。
- 您只是临时试用 OceanWay AI。
- 您想撤销本工具写入的配置。

点击“恢复默认”后，请重启 Codex。

## 十、常见问题

### 1. 我需要修改 Base URL 吗？

通常不需要。

默认 Base URL 是：

```text
https://ocean-way.top
```

除非 OceanWay AI 工作人员明确要求您修改，否则请保持默认。

### 2. 配置完成后为什么还要完全退出并重新打开 Codex？

Codex 启动时会读取 provider 配置并注册可用工具。配置完成后，需要完全退出并重新打开 Codex，再创建新任务，才能让新的 provider 和图片工具配置生效。只关闭窗口或继续使用旧任务可能不会重新注册工具。

### 3. API Key 输入后为什么看不到明文？

这是正常的。为了避免旁人看到您的 API Key，输入框默认会隐藏内容。

如果需要检查，可以点击输入框右侧的眼睛图标显示或隐藏。

### 4. 恢复默认会删除我的其他 Codex 配置吗？

正常情况下不会。

本工具会在第一次配置前保存一份原始配置。点击“恢复默认”时，会优先恢复这份原始配置。

### 5. 我不小心填错了 API Key 怎么办？

重新打开软件，填写正确的 API Key，再点击“一键配置并重启”即可。

### 6. 软件打不开怎么办？

请先确认您下载的是对应系统的版本：

- macOS 使用 `codex-config-macOS.zip`
- Windows 使用 `.exe`

如果仍然无法打开，请联系 OceanWay AI 工作人员，并说明：

- 您的电脑系统是 macOS 还是 Windows。
- 出现了什么提示。
- 您操作到了哪一步。

### 7. 为什么显示“图片能力：待配置”？

这表示图片 MCP 或短规则尚未完整配置。保持 Key 输入框为空，重新执行一键配置，然后新建 Codex 任务。若有其他来源的同名 MCP，工具会停止并提示，不直接覆盖。工具握手通过不等于图片接口或自然语言流程已实测通过。

## 十一、给用户的简短操作版

Windows 版本优先检测和重启 ChatGPT，兼容开始菜单注册的商店版本及常见安装目录。状态会区分“ChatGPT 已运行，Codex 待启动”“ChatGPT 内运行”和“检测失败”。进程运行不等于配置已经被新任务加载。

自动重启只请求正常退出，不强制结束进程。如果有保存提示或应用仍驻留托盘，流程会停止；请保存任务、完全退出 ChatGPT 后重试。重新启动后仍需进入 Codex 并新建任务。

如果您只想快速完成配置，请按这几步操作：

1. 下载并打开 `codex-config`。
2. 粘贴 API Key。
3. 确认 Base URL 是 `https://ocean-way.top`。
4. 保存正在进行的任务，点击“一键配置并重启”。
5. 等待自动完成，在重新打开的 Codex 中新建任务。
