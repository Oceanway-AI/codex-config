# Oceanway Config 使用说明

Oceanway Config 基于 CC Switch，帮助你把 Oceanway API 配到本机的 Codex、Claude Code 等应用。首次使用按首页三个步骤操作即可。

本版提供 Codex 桌面版、Claude Desktop、Claude Code 终端版、DeepSeek Harness 桌面版、Hermes 桌面版和 Kimi Code Desktop。

## Mac 用户：首次安装与打开

下面的步骤适用于从 Oceanway 官网下载的本版 Oceanway Config。Mac 上输入命令的工具叫“终端”，不叫 CMD。

### 第一步：下载对应版本

点击屏幕左上角的苹果图标 →“关于本机”，查看芯片或处理器：

- 显示 Apple M 系列芯片：下载 `Oceanway-Config-macos-arm64.zip`。
- 显示 Intel 处理器：下载 `Oceanway-Config-macos-intel.zip`。

### 第二步：把应用放进“应用程序”

1. 打开“访达”（Dock 栏里的蓝白笑脸图标），进入“下载”文件夹。
2. 双击下载好的 ZIP 压缩包，解压出 `Oceanway Config.app`。
3. 把它拖到访达左侧的“应用程序”中，保留原来的名称。如果没有显示 `.app` 后缀，只显示 `Oceanway Config`，也是正常的。
4. 从“应用程序”中双击打开 Oceanway Config。如果可以正常打开，就不用执行下面的终端命令。
5. 如果提示“已损坏，无法打开”或开发者无法验证，先关闭提示，保留应用，再按下面步骤处理。

### 第三步：打开“终端”

1. 同时按住键盘上的 **Command（⌘）+ 空格键**，打开搜索框。
2. 输入“终端”或 `Terminal`，按回车键打开。
3. 出现一个可以输入文字的窗口，就是终端。

也可以通过“访达”→“应用程序”→“实用工具”→“终端”打开。

### 第四步：复制命令并运行

完整复制下面这一行：

```bash
xattr -dr com.apple.quarantine "/Applications/Oceanway Config.app"
```

点击终端窗口，按 **Command（⌘）+ V** 粘贴，然后按一次 **回车键（Return / Enter）**。

命令中的引号、空格和应用名称都要保留，不需要输入代码框上方的 `bash` 或任何其他文字。

执行成功时通常没有“成功”提示。只要没有出现错误文字，窗口重新出现可以输入命令的一行，就可以进行下一步。

### 第五步：重新打开应用

回到“访达”→“应用程序”，双击 `Oceanway Config`。如果系统询问是否打开从互联网下载的应用，点击“打开”。进入应用后，按下面的“连接 Oceanway”步骤继续配置。

正常打开后可以关闭终端。**同一份应用通常只需要处理一次，之后直接双击打开即可。重新下载或更新替换应用后，可能需要再处理一次。**

### 命令执行时遇到问题

- **出现 `No such file or directory`**：表示没有找到应用。确认已经把解压出的应用拖进“应用程序”，名称仍为 `Oceanway Config.app`，再复制命令执行。
- **出现 `Permission denied`**：表示权限不足，可以改用下面这一行：

  ```bash
  sudo xattr -dr com.apple.quarantine "/Applications/Oceanway Config.app"
  ```

  按回车后，如果出现 `Password:`，输入这台 Mac 的管理员登录密码，再按回车。输入密码时不会显示文字、圆点或星号，这是正常现象；不要输入 Oceanway 密码或 API Key。

- **仍提示无法打开，或出现其他错误**：把终端报错和打开应用时的提示截图发给 Oceanway 技术人员核对。

## 1. 连接 Oceanway

左侧栏“登录 Oceanway 官网”会打开 https://oceanway.tech。登录后可进入 Console 管理 API Key、查看调用情况。

在“连接 Oceanway”中粘贴 API Key，点击“连接并继续”。服务地址默认是 `https://console.oceanway.tech/v1`，也可以自己修改，或点击“恢复默认”。

连接成功后，应用会读取这个 Key 可用的模型，并显示实际服务地址。需要调整时点击“更换 Key 或地址”，重新连接。保存后，Agent 和图片工具使用这组地址与 Key。

## 2. 选择应用

首页显示全部六款应用。未安装时点击“下载安装”，程序从 Oceanway 服务器下载完整包，显示进度并校验。下载完成后点击“打开安装包”，按系统向导装好，再点击“检测安装结果”。Claude Code 下载完成后点击“安装 Claude Code”。安装进度只显示在对应 Agent 区域。左下角“应用”可查看六款应用的安装状态。

多个应用可以同时下载，不用等前一个结束。每个应用都能单独取消、重试或打开安装包；切换页面后，下载继续。

Mac 打开 DMG 后将应用拖入“应用程序”，或按 PKG 向导安装；Claude Code 装入默认用户目录。当前 Hermes 没有 Mac Intel 包，对应系统会显示不可安装；Windows Hermes 需要 Windows 11 22H2 或更新版本。

模型会自动选好：Codex 默认 GPT，Claude 系列默认 Claude，DeepSeek Harness 默认 DeepSeek，Kimi 默认 Kimi。点击“选择模型”查看真实清单，可同时勾选多个模型并指定默认模型。保存后可在 Agent 内切换。图片模型也可多选，在“生图设置”调整；对话时直接告诉 AI 使用哪个图片模型，未指定时使用默认模型。

电脑上已经有 Codex？看到“已安装”就直接选它，不用重装。刚装好的，回到 Oceanway 点“检测安装结果”。Windows 不用再去微软商店；Mac 如果打开的是安装盘，先把应用拖进“应用程序”。

选好应用后点击“一键配置”。如果 Key 没有图片模型权限，页面会提示，你仍可先完成对话配置。

## 3. 开始使用

如果点击“一键配置”后提示 Codex 仍在运行，即使它的窗口已经关了，也请先保存工作、等任务结束，再点“已保存，退出并配置”。程序会关闭 Codex 及其后台服务，再写入配置。点“取消”可以先回去继续工作。

配置成功后点击“打开 Codex”。如果你中途又打开过 Codex，先保存工作，再点“已保存，重启 Codex”。看到新窗口就可以开始对话。若提示没有检测到窗口，直接重试打开，无需重新填写 Key。Claude Code 则会打开新终端。

如果某项失败，结果会显示原因；已经成功的项目会保留。点击“返回调整”可重新配置。

## 在对话中生图

一键配置会向选中的 Agent 注册 Oceanway 图片 MCP，并写入默认生图规则。打开新会话后，直接用自然语言描述图片，例如：

> 帮我生成两张不同构图的海边咖啡馆宣传图。

Agent 会通过 Oceanway 图片工具提交任务，多张图片可以并行生成，再把结果返回当前会话。图片工具会查询这个 Key 的全部可用图片模型，可以说“列出可用的图片模型”，再指定其中一个生成；没有指定时使用默认模型。若提示没有图片模型，先确认该 Key 已开通图片能力，再重新连接配置。

需要图生图时，把本地图片上传到 Agent，再说明修改要求，例如“把这张图里的船帆改成紫色”。图片工具读取附件原文件，结果另存，保留原图。也可以提供图片的真实 HTTPS 链接。各服务与模型的实测情况见 [图片核验记录](functional-verification.md#图片逐模型结果)。

默认 Console 按 [Oceanway 平台文档](https://docs.oceanway.tech/docs/)接入，自定义地址按模型目录选择 OpenAI 或 Gemini 协议。需要等待时查询原任务，网络中断后可继续获取原结果。

## 查找以前的会话

点击侧栏“会话”，可以集中查看各 Agent 保存在本机的记录。选择应用，按项目或时间分组，搜索标题、摘要、会话 ID 或目录；打开某条记录后可阅读消息、图片和工具调用，在正文里查找，复制单轮或整段对话，并导出 Markdown。

Codex 的普通与归档会话都会读取。隐藏某个侧栏应用入口后，已有历史仍能在会话页找到。Claude Desktop 入口显示的是本地 Claude Code 记录。

接入 Oceanway 时会自动完成历史可见性兼容：先备份，再处理必要的供应商标记，保留会话 ID、正文和附件；无需单独迁移。Codex 沿用 CC Switch 的统一历史设置，切回已保存的官方或其他供应商时继续使用同一份本地历史。Claude Code 保留原项目目录中的会话。

需要回到 Agent 继续时，可复制“恢复命令”在原项目目录运行；macOS 还可直接在所选终端恢复。旧会话能否直接续聊由 Agent 与原会话状态决定；原客户端支持时也可从旧会话创建分支。

阅读、搜索和复制不会删除记录。会话页的“删除”是永久删除，必须在确认框中确认后才执行。

## 其他入口

| 入口              | 用途                                                       |
| ----------------- | ---------------------------------------------------------- |
| 高级功能 → MCP    | 添加、编辑、导入工具服务，选择同步到哪些应用               |
| 高级功能 → Skills | 查找、安装和管理技能，选择使用技能的应用                   |
| 高级功能 → 提示词 | 编辑、启用、导入和复制提示词                               |
| 应用              | 查看 Agent 状态、下载安装及重新检测                    |
| 设置              | 调整语言、外观、应用目录、网络、备份、导出及日志等         |

## 遇到问题

- **连接失败**：检查 Key 和网络，按页面提示重新连接。
- **安装后未识别**：点击“重新检测”，或到“应用”查看对应安装状态和错误。
- **配置后仍用旧模型**：保存工作后通过结果页打开应用，CLI 使用新终端。
- **会话列表读取失败**：点击“重试”；读取请求失败会明确显示，已加载的记录会保留。
- **图片配置失败**：查看结果页的图片状态，确认 Key 的图片权限后重试。

各功能的测试记录和当前验证范围见 [功能核验记录](functional-verification.md)。
