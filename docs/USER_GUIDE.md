# OceanWay Codex 配置

## 一键配置

1. 打开对应系统的程序。
2. 填写 `Base URL` 和 `API Key`。OceanWay 默认地址为 `https://ocean-way.top`，也支持 `https://ocean-way.top/v1`。
3. 保存 Codex / ChatGPT 中正在进行的任务，点击“一键配置并重启”。
4. 等待完成，在重新打开的 Codex 中新建任务。

软件自动备份原配置、写入服务地址和认证、安装直接图片 API 规则、回读检查并请求重启。用户不需要单独配置图片模型、安装生图 CLI 或运行命令。

已保存 Key 时，输入框留空即可继续使用原 Key；填写新 Key 才会替换。界面和诊断报告不回显已保存的完整 Key。

主界面只保留连接设置、一键配置、迁移历史、恢复原配置及“高级”入口。

## 在 Codex 中生图

新建任务后，自然表达需求即可，例如：

- “生成六张不同风格的咖啡海报。”
- 附上参考图后说：“参考这张图做三个版本。”
- “把第二张改成横版。”

默认图片模型为 `gpt-image-2`。明确指定其他模型时按指定执行，不自动更换模型。数量按要求处理，未指定才默认一张；最多两个请求同时执行，不是总数量上限。

无参考图调用当前服务的图片生成接口；有参考图上传真实图片到编辑接口。继续修改使用上一轮真实输出并保留原图。参考图直接附在 Codex 对话中，不需要再传到配置工具。

如果当前任务无法读取附件原图，Codex 应说明情况并请求可读文件，不能把“看图后的文字描述”当成原图上传。模型权限、服务额度或接口故障应按实际结果反馈。超时不会自动重复提交收费请求。

一键配置不会生成图片，也不扣除图片测试额度。配置成功仅表示写入及检查完成，不代表已实测所有图片接口。

## 迁移历史

切换服务后看不到旧任务时，点击首页“迁移历史”。

软件先扫描需要迁移的会话和索引数量，确认后自动备份，再调整 provider 元数据。不修改对话正文，也不会在一键配置或打开“高级”时自动迁移。

包含加密内容的会话可能只能恢复列表可见性，不保证能够继续对话；确认前会提示。

备份位置：`$CODEX_HOME/oceanway-history-migration-backup/`。

## 恢复原配置

点击首页“恢复原配置”，确认后恢复首次使用本工具之前的配置快照，并撤销由本工具记录的历史迁移。迁移后新建的会话不会被强行转回旧 provider。

**恢复会覆盖首次备份之后的手动配置修改。** 操作前可在“高级 → 运维工具 → 配置与备份目录”检查备份。

首次配置备份位置：`$CODEX_HOME/oceanway-ai-backup/`。恢复后需要重启 Codex。

## 高级工具

平时不需要打开“高级”。出现问题或需要检查时，里面保留：

- 当前配置和 Codex 运行状态。
- 问题诊断与复制脱敏报告。
- 测试服务连接、修复配置、同步图片规则、重启 Codex、打开配置与备份目录。
- 本次打开的配置日志，最多 200 条，不记录完整 Key。
- 检查更新。
- 图片 API 测试。

“测试服务连接”只检查连接，不生成图片。

图片测试可指定模型、数量、尺寸及多张参考图。点击测试并确认可能产生费用后才提交请求；模型列表检查本身不生图。成功结果逐项保存，部分失败不会丢弃已成功的图片。

重试只补失败或取消项，并需要再次确认费用。取消只能停止尚未发出的请求，已提交的请求可能仍完成或计费。测试中请保持程序开启，本版不在重启程序后自动恢复收费任务。

测试文件位置：`$CODEX_HOME/oceanway-image-tests/`。正常 Codex 对话生图的结果保存到当前项目的 `output/images/`。

## 配置中断

- 写入或回读失败：后续重启停止，按提示检查地址、Key 或配置目录。
- 显示“已保存，待重启”：配置已保存，但自动重启未完成。保存任务后手动重启目标 Codex；不能把它当成保存失败。
- 重试检查或重启：不会重复写入已保存配置。修改地址或 Key 后再重试，会先保存新输入。
- 损坏的配置或认证文件：停止处理，不静默覆盖。

隔离测试程序使用独立 `CODEX_HOME`，会拒绝自动重启当前全局 Codex，避免打断正在使用的环境。这是保护措施，不是生图接口故障。

## 下载与更新

Windows 使用 Windows 安装包或可执行文件；macOS 使用对应 Apple Silicon / Intel 构建。用户不需要安装 Rust、Cargo 或 Visual C++ 编译工具。

“高级 → 运维工具 → 检查更新”会检查已发布的签名更新。更新通道不可用只表示没有取得有效更新清单，不代表是最新版，也不影响本地配置。

`1.4.0-beta.3` 是测试分支版本，不会自动发布为正式更新。

## 开发验证

`npm test` 运行前端单元测试；`cargo test --manifest-path src-tauri/Cargo.toml` 运行 Rust 回归测试。

`npm run test:ui` 在 `127.0.0.1:4186` 提供仅使用假数据的界面。使用本地 Playwright 运行：

```text
node tests/simple-ui-smoke.mjs
node tests/image-ui-smoke.mjs
```

可用 `PLAYWRIGHT_MODULE` 指定已安装的 Playwright `index.mjs`。模拟界面不读取真实配置、不发送 Key、不重启应用，也不会打包进软件；模拟通过不代表真实服务测试通过。

核心图片 API 和独立 Codex 会话已完成真实测试。发布前只需补充一次有代表性的桌面对话附件生图验收，不要求逐一重测 Codex 自带的上传、拖拽、粘贴入口。完整范围见 `DIRECT_IMAGE_BETA.md`。
